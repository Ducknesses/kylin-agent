
# 麒麟智能运维 Agent (kylin-agent) 软件功能测试目录

> **编制依据**: 《功能设计文档》v1.0 + 中国软件杯A2赛题要求
> **编制日期**: 2026-07-19
> **测试对象**: kylin-agent 全系统（Backend + Frontend + MCP Server）

---

## 一、测试概述

### 1.1 测试目的
验证kylin-agent系统是否符合中国软件杯A2赛题"面向麒麟操作系统的安全智能运维Agent"的全部功能要求，确保系统可用、安全、稳定。

### 1.2 测试范围
| 层级 | 测试对象 | 说明 |
|------|---------|------|
| 前端 | Vue 3 + Vite 应用 | 用户交互界面 |
| 后端 | FastAPI + 多Agent编排 | 业务逻辑与API接口 |
| MCP Server | JSON-RPC 2.0 服务 | 系统操作执行端 |
| 安全 | 七层纵深防御体系 | 安全防护机制 |
| 部署 | 三端独立部署脚本 | 安装/卸载/配置 |

### 1.3 测试环境要求
- 控制节点: x86_64/ARM/LoongArch架构，Ubuntu 22.04 / CentOS 8
- 目标机: 麒麟V11 (LoongArch架构)
- Python 3.10+
- Node.js 18+
- Redis 6.0+ (或fakeredis)
- Nginx 1.20+
