## 一、测试概述

### 1.1 测试目的

验证 kylin-agent 系统在正常负载和并发场景下的性能表现，确保系统响应时间、吞吐量、资源占用等核心指标满足设计要求和生产环境部署需要。

### 1.2 核心指标总览

| 指标编号 | 指标名称 | 目标值 | 优先级 |
|---------|---------|--------|--------|
| PERF-001 | API 响应时间 | `/health` < 100ms | P1 |
| PERF-002 | 并发会话创建 | 100 并发全部成功 | P1 |
| PERF-003 | WebSocket 并发连接 | 100 并发连接稳定 | P1 |
| PERF-004 | SSE 推送性能 | 100 客户端推送无延迟 | P1 |
| PERF-005 | 审计写入性能 | 高并发写入无丢失 | P1 |
| PERF-006 | 数据库查询性能 | 大量记录查询 < 1s | P2 |
| PERF-007 | 前端首屏加载 | < 3s | P2 |
| PERF-008 | 内存占用 | 长时间运行无泄漏 | P1 |
| PERF-009 | CPU 占用 | 高负载下不过载 | P1 |
| PERF-010 | MCP 调用延迟 | Mock < 10ms, Real < 500ms | P1 |

## 三、核心性能指标定义

### 3.1 指标层级说明

| 层级 | 说明 | 典型指标 |
|------|------|---------|
| L1 - 系统级 | 操作系统资源占用 | CPU使用率、内存使用量、磁盘IO |
| L2 - 服务级 | 后端服务自身性能 | API响应时间、并发连接数、请求吞吐量 |
| L3 - 业务级 | 端到端业务操作性能 | 会话创建耗时、WebSocket消息延迟、MCP工具调用延迟 |
| L4 - 体验级 | 前端用户体验性能 | 首屏加载时间、消息渲染延迟、页面切换速度 |

### 3.2 指标详细定义

#### 3.2.1 API 响应时间 (PERF-001)

| 属性 | 值 |
|------|-----|
| 指标描述 | 后端 API 接口从接收请求到返回响应的耗时 |
| 测量端点 | `GET /health`, `GET /api/sessions`, `POST /api/sessions` |
| 测量方法 | `curl -w` 获取 `time_total`，连续测量 50 次取 P50/P95/P99 |
| 目标值 | P95 < 100ms（health）, P95 < 500ms（业务接口） |
| 采集工具 | curl + shell 脚本 |

#### 3.2.2 并发会话创建 (PERF-002)

| 属性 | 值 |
|------|-----|
| 指标描述 | 系统在并发请求下创建会话的成功率和耗时 |
| 并发数 | 100 |
| 测量方法 | 使用 `xargs -P` 并行执行 curl POST 请求 |
| 目标值 | 成功率 100%, P95 耗时 < 2s |

#### 3.2.3 WebSocket 并发连接 (PERF-003)

| 属性 | 值 |
|------|-----|
| 指标描述 | 同时维持多个 WebSocket 连接时系统的稳定性 |
| 并发数 | 100 |
| 测量方法 | 使用 Python websockets 库并行建立连接并发送/接收消息 |
| 目标值 | 100 连接全部建立成功，消息延迟 < 5s |

#### 3.2.4 SSE 推送性能 (PERF-004)

| 属性 | 值 |
|------|-----|
| 指标描述 | 多个客户端同时订阅 SSE 监控流时的推送延迟和资源消耗 |
| 并发数 | 100 |
| 测量方法 | 并行 curl 连接 SSE 端点，统计收到首个事件的延迟 |
| 目标值 | 首个事件延迟 < 5s, CPU 增幅 < 30% |

#### 3.2.5 审计写入性能 (PERF-005)

| 属性 | 值 |
|------|-----|
| 指标描述 | 高并发审计日志写入时的数据完整性和哈希链正确性 |
| 并发数 | 50 并发请求 |
| 测量方法 | 并行发送 API 操作请求，验证审计记录是否完整 |
| 目标值 | 0 条丢失，哈希链完整 |

#### 3.2.6 数据库查询性能 (PERF-006)

| 属性 | 值 |
|------|-----|
| 指标描述 | 大量审计记录下的分页查询响应时间 |
| 数据量 | 10,000 条审计记录 |
| 测量方法 | 预热数据后执行分页查询，测量响应时间 |
| 目标值 | < 1s |

#### 3.2.7 前端首屏加载 (PERF-007)

| 属性 | 值 |
|------|-----|
| 指标描述 | 前端页面从请求到首次内容渲染的时间 |
| 测量方法 | 浏览器 DevTools → Performance 或 Lighthouse |
| 目标值 | FCP < 1.5s, LCP < 3s |

#### 3.2.8 内存占用 (PERF-008)

| 属性 | 值 |
|------|-----|
| 指标描述 | 后端进程在长时间运行后的内存使用情况 |
| 测量时长 | 持续运行 1 小时 |
| 测量方法 | 每 60 秒采样一次 RSS，观察趋势 |
| 目标值 | 无持续增长趋势（内存泄漏判定：增长率 > 10%/h） |

#### 3.2.9 CPU 占用 (PERF-009)

| 属性 | 值 |
|------|-----|
| 指标描述 | 后端进程在高负载下的 CPU 使用率 |
| 负载条件 | 50 并发持续请求 |
| 测量方法 | `ps -p <PID> -o %cpu` 持续采样 |
| 目标值 | 平均 < 50%，峰值 < 80% |

#### 3.2.10 MCP 调用延迟 (PERF-010)

| 属性 | 值 |
|------|-----|
| 指标描述 | MCP 工具调用的端到端延迟（Mock vs Real 模式） |
| 测试工具 | sys_info, log_read, net_monitor |
| 测量方法 | curl 调用后端 API 触发 MCP 调用，测量后端处理耗时 |
| 目标值 | Mock < 10ms, Real < 500ms |

### 4.7 PERF-007 前端加载性能测试

**测试目的**: 测量前端页面首屏加载速度。

#### 方法一：使用浏览器 DevTools（推荐）

1. 打开 Chrome/Edge 浏览器，访问你的 kylin-agent 前端地址（如 `https://192.168.1.x`）
2. 按 `F12` 打开 DevTools
3. 切换到 **Network** 标签页
4. 勾选 **Disable cache**
5. 切换到 **Performance** 标签页
6. 点击 ⬤ 开始录制
7. 刷新页面（`Ctrl+Shift+R` 强制刷新）
8. 等待页面完全加载后停止录制
9. 查看以下指标：
   - **FCP** (First Contentful Paint): 首次内容绘制时间 — 目标 < 1.5s
   - **LCP** (Largest Contentful Paint): 最大内容绘制时间 — 目标 < 3s
   - **TTI** (Time to Interactive): 可交互时间 — 目标 < 4s

#### 方法二：使用 Lighthouse

1. 打开 Chrome DevTools → **Lighthouse** 标签页
2. Mode 选择 **Navigation**
3. Categories 勾选 **Performance**
4. 点击 **Analyze page load**
5. 记录 Performance 评分和关键指标

#### 方法三：命令行快速检查


> **脚本文件**: 详见 [附录 B.7](#b.7-perf-007-前端加载性能)

### 4.10 PERF-010 MCP调用延迟测试

**测试目的**: 测量通过 MCP 调用工具的端到端延迟。

#### 步骤 1：确认 MCP Server 运行中

```bash
# 检查 MCP Server 健康状态
curl -s http://127.0.0.1:8001/health 2>/dev/null || echo "MCP Server 未运行（将使用 Mock 模式）"
```

#### 步骤 2：执行 MCP 调用延迟测试

```bash
cat > /tmp/perf_mcp_latency.sh << 'SCRIPT'
#!/bin/bash
# ============================================
# PERF-010: MCP 调用延迟测试
# ============================================
API_BASE="http://127.0.0.1:8000"
TOKEN="123456789"
SAMPLES=30

echo "=== PERF-010: MCP 调用延迟测试 ==="
echo "采样次数: ${SAMPLES}"
echo ""

# 测试通过后端 API 触发 MCP 调用的延迟
# 使用 /api/monitor/metrics（内部会调用 MCP）

echo "--- GET /api/monitor/metrics (含 MCP 调用) ---"
MONITOR_FILE="/tmp/perf_mcp_times.txt"
> "$MONITOR_FILE"

for i in $(seq 1 $SAMPLES); do
  RESULT=$(curl -s -o /dev/null -w "%{time_total}" \
    "${API_BASE}/api/monitor/metrics" \
    -H "Authorization: Bearer ${TOKEN}" 2>/dev/null)
  if [ -n "$RESULT" ]; then
    echo "$RESULT" >> "$MONITOR_FILE"
  fi
done

if [ -s "$MONITOR_FILE" ]; then
  sort -n "$MONITOR_FILE" > /tmp/perf_mcp_sorted.txt
  COUNT=$(wc -l < /tmp/perf_mcp_sorted.txt)
  AVG=$(awk '{sum+=$1} END {printf "%.3f", sum/NR}' /tmp/perf_mcp_sorted.txt)
  P50=$(awk "NR==int(${COUNT}*0.5)" /tmp/perf_mcp_sorted.txt)
  P95=$(awk "NR==int(${COUNT}*0.95)" /tmp/perf_mcp_sorted.txt)

  echo "  成功采样: ${COUNT}/${SAMPLES}"
  echo "  平均: ${AVG}s"
  echo "  P50: ${P50}s"
  echo "  P95: ${P95}s"

  P95_MS=$(echo "$P95 * 1000" | bc 2>/dev/null || awk "BEGIN {printf \"%.0f\", $P95 * 1000}")

  # 检查 MCP 模式
  MCP_MODE=$(grep MCP_MODE /home/jackb/projects/kylin-agent/backend/.env 2>/dev/null | cut -d'=' -f2 || echo "unknown")
  echo ""
  echo "  MCP 模式: ${MCP_MODE}"

  if [ "$MCP_MODE" = "mock" ] || [ "$MCP_MODE" = "Mock" ]; then
    TARGET_MS=10
    echo "  目标 (Mock): P95 < ${TARGET_MS}ms"
  else
    TARGET_MS=500
    echo "  目标 (Real): P95 < ${TARGET_MS}ms"
  fi

  if [ -n "$P95_MS" ] && [ "$P95_MS" -lt "$TARGET_MS" ] 2>/dev/null; then
    echo "  判定: ✅ 通过 (P95 = ${P95_MS}ms < ${TARGET_MS}ms)"
  else
    echo "  判定: ❌ 不通过 (P95 = ${P95_MS}ms, 目标 < ${TARGET_MS}ms)"
  fi
else
  echo "  ❌ 采样失败"
fi

rm -f "$MONITOR_FILE" /tmp/perf_mcp_sorted.txt
SCRIPT

chmod +x /tmp/perf_mcp_latency.sh
bash /tmp/perf_mcp_latency.sh
```

**记录结果**:
| 指标 | 目标 | 实际值 | 判定 |
|------|------|--------|------|
| MCP 模式 | Mock / Real | ___ | |
| P95 延迟 | Mock<10ms / Real<500ms | ___ ms | |

### B.3 PERF-003 WebSocket并发连接测试脚本

> 对应测试项: [4.3 PERF-003 WebSocket并发连接](#43-perf-003-websocket并发连接)

```bash
cat > /tmp/perf_ws_concurrent.py << 'SCRIPT'
#!/usr/bin/env python3
"""PERF-003: WebSocket 并发连接测试

依赖: pip install websockets
"""
import asyncio
import time
import sys
import json

API_BASE = "http://127.0.0.1:8000"
WS_BASE = "ws://127.0.0.1:8000"
TOKEN = "123456789"
CONCURRENT = 100

# 先创建测试会话
import urllib.request

def create_session():
    data = json.dumps({"title": "perf-ws-test"}).encode()
    req = urllib.request.Request(
        f"{API_BASE}/api/sessions",
        data=data,
        headers={
            "Authorization": f"Bearer {TOKEN}",
            "Content-Type": "application/json",
        },
        method="POST",
    )
    resp = urllib.request.urlopen(req)
    body = json.loads(resp.read())
    return body.get("id")

session_id = create_session()
print(f"测试会话 ID: {session_id}")

# 每个客户端: 连接 → 发送消息 → 等待首个响应 → 关闭
async def ws_client(client_id):
    try:
        import websockets
    except ImportError:
        print("请先安装 websockets: pip install websockets")
        sys.exit(1)

    uri = f"{WS_BASE}/ws/chat/{session_id}?token={TOKEN}"
    try:
        async with websockets.connect(uri, close_timeout=2) as ws:
            await ws.send(json.dumps({"type": "message", "content": f"perf test {client_id}"}))
            # 等待第一个响应（最多 30 秒）
            response = await asyncio.wait_for(ws.recv(), timeout=30.0)
            return {"client_id": client_id, "status": "success", "response_length": len(response)}
    except asyncio.TimeoutError:
        return {"client_id": client_id, "status": "timeout"}
    except Exception as e:
        return {"client_id": client_id, "status": "error", "error": str(e)}

async def main():
    print(f"启动 {CONCURRENT} 个并发 WebSocket 连接...")
    start_time = time.time()

    tasks = [ws_client(i) for i in range(CONCURRENT)]
    results = await asyncio.gather(*tasks)

    elapsed = time.time() - start_time

    success = sum(1 for r in results if r["status"] == "success")
    timeout_count = sum(1 for r in results if r["status"] == "timeout")
    error_count = sum(1 for r in results if r["status"] == "error")

    print(f"\n=== PERF-003 结果 ===")
    print(f"并发数: {CONCURRENT}")
    print(f"成功: {success}")
    print(f"超时: {timeout_count}")
    print(f"错误: {error_count}")
    print(f"总耗时: {elapsed:.2f}s")
    print(f"成功率: {success / CONCURRENT * 100:.1f}%")

    if success >= CONCURRENT * 0.95:
        print("判定: ✅ 通过 (成功率 >= 95%)")
    else:
        print("判定: ❌ 不通过")

if __name__ == "__main__":
    asyncio.run(main())
SCRIPT
```

```bash
  if [ -n "$P95_MS" ] && [ "$P95_MS" -lt 1000 ] 2>/dev/null; then
    echo "  判定: ✅ 通过 (P95 < 1s)"
  else
```

```bash
cat > /tmp/perf_memory_monitor.sh << 'SCRIPT'
#!/bin/bash
# ============================================
# PERF-008: 内存占用监控（1 小时）
# ============================================
DURATION=3600          # 1 小时
INTERVAL=60            # 每 60 秒采样一次
API_BASE="http://127.0.0.1:8000"
TOKEN="123456789"

PID=$(pgrep -f "python.*run.py" | head -1)
if [ -z "$PID" ]; then
  echo "❌ 未找到后端进程"
  exit 1
fi

echo "=== PERF-008: 内存占用监控 ==="
echo "进程 PID: ${PID}"
echo "监控时长: ${DURATION}s (${DURATION}秒)"
echo "采样间隔: ${INTERVAL}s"
echo "开始时间: $(date)"
echo ""

LOG_FILE="/tmp/perf_memory_log.csv"
echo "timestamp,elapsed_sec,rss_mb,vsz_mb,cpu_pct" > "$LOG_FILE"

START_TS=$(date +%s)
ELAPSED=0

while [ $ELAPSED -lt $DURATION ]; do
  NOW_TS=$(date +%s)
  ELAPSED=$(( NOW_TS - START_TS ))

  # 获取进程资源
  PROC_INFO=$(ps -p $PID -o rss=,vsz=,%cpu= --no-headers 2>/dev/null)
  if [ -z "$PROC_INFO" ]; then
    echo "❌ 进程已退出"
    break
  fi

  RSS_KB=$(echo "$PROC_INFO" | awk '{print $1}')
  VSZ_KB=$(echo "$PROC_INFO" | awk '{print $2}')
  CPU_PCT=$(echo "$PROC_INFO" | awk '{print $3}')

  RSS_MB=$(awk "BEGIN {printf \"%.1f\", $RSS_KB / 1024}")
  VSZ_MB=$(awk "BEGIN {printf \"%.1f\", $VSZ_KB / 1024}")

  echo "$(date -Iseconds),${ELAPSED},${RSS_MB},${VSZ_MB},${CPU_PCT}" >> "$LOG_FILE"

  # 进度提示
  MINUTES=$(( ELAPSED / 60 ))
  echo "  [${MINUTES}min] RSS: ${RSS_MB} MB | VSZ: ${VSZ_MB} MB | CPU: ${CPU_PCT}%"

  sleep $INTERVAL
done

echo ""
echo "--- 监控完成 ---"
echo "结束时间: $(date)"
echo "数据文件: ${LOG_FILE}"

# 分析趋势
if [ -f "$LOG_FILE" ]; then
  LINE_COUNT=$(tail -n +2 "$LOG_FILE" | wc -l)
  if [ "$LINE_COUNT" -gt 2 ]; then
    FIRST_RSS=$(tail -n +2 "$LOG_FILE" | head -1 | cut -d',' -f3)
    LAST_RSS=$(tail -1 "$LOG_FILE" | cut -d',' -f3)

    echo ""
    echo "--- 内存趋势分析 ---"
    echo "  初始 RSS: ${FIRST_RSS} MB"
    echo "  最终 RSS: ${LAST_RSS} MB"

    GROWTH=$(awk "BEGIN {printf \"%.1f\", (${LAST_RSS} - ${FIRST_RSS}) / ${FIRST_RSS} * 100}" 2>/dev/null || echo "N/A")
    echo "  增长率: ${GROWTH}%"

    # 判定（增长率 > 10% 可能存在泄漏）
    if awk "BEGIN {exit !(${GROWTH} > 10)}" 2>/dev/null; then
      echo "  判定: ⚠️  警告 (内存增长 ${GROWTH}%，可能存在泄漏)"
    else
      echo "  判定: ✅ 通过 (增长 < 10%)"
    fi
  fi
fi

echo ""
echo "详细 CSV 数据: ${LOG_FILE}"
echo "使用以下命令查看趋势图:"
echo "  cat ${LOG_FILE} | column -t -s','"
SCRIPT

chmod +x /tmp/perf_memory_monitor.sh
bash /tmp/perf_memory_monitor.sh
```

```bash
cat > /tmp/perf_cpu_load.sh << 'SCRIPT'
#!/bin/bash
# ============================================
# PERF-009: CPU 占用测试（50并发负载）
# ============================================
API_BASE="http://127.0.0.1:8000"
TOKEN="123456789"
DURATION=60           # 负载持续时间（秒）

PID=$(pgrep -f "python.*run.py" | head -1)
if [ -z "$PID" ]; then
  echo "❌ 未找到后端进程"

# 后台采样 CPU

echo "timestamp,cpu_pct" > "$CPU_LOG"

sample_cpu() {
  while true; do
    CPU=$(ps -p $PID -o %cpu --no-headers 2>/dev/null)
    echo "$(date +%s),${CPU}" >> "$CPU_LOG"
    sleep 1
  done
}

sample_cpu &
SAMPLE_PID=$!

# 发送持续并发请求
echo "开始发送 ${CONCURRENT} 并发请求..."
START_TIME=$(date +%s)

while [ $(( $(date +%s) - START_TIME )) -lt $DURATION ]; do
  for i in $(seq 1 $CONCURRENT); do
    curl -s -o /dev/null "${API_BASE}/health" &
  done
  wait 2>/dev/null
done

# 停止采样
kill $SAMPLE_PID 2>/dev/null
wait $SAMPLE_PID 2>/dev/null

echo ""
echo "--- CPU 统计 ---"
if [ -f "$CPU_LOG" ] && [ $(wc -l < "$CPU_LOG") -gt 1 ]; then
  tail -n +2 "$CPU_LOG" | awk -F',' '{
    sum+=$2; count++
    if ($2 > max || max == "") max=$2
    if ($2 < min || min == "") min=$2
  } END {
    printf "  平均 CPU: %.1f%%\n", sum/count
    printf "  峰值 CPU: %.1f%%\n", max
    printf "  最低 CPU: %.1f%%\n", min
  }'

  AVG_CPU=$(tail -n +2 "$CPU_LOG" | awk -F',' '{sum+=$2; n++} END {printf "%.1f", sum/n}')
  MAX_CPU=$(tail -n +2 "$CPU_LOG" | awk -F',' '{if($2>m||m=="")m=$2} END {printf "%.1f", m}')

  # 判定
  PASS=true
  if awk "BEGIN {exit !(${AVG_CPU} > 50)}" 2>/dev/null; then
    echo "  判定-平均: ❌ 不通过 (平均 ${AVG_CPU}% > 50%)"
    PASS=false
  else
    echo "  判定-平均: ✅ 通过 (平均 ${AVG_CPU}% < 50%)"
  fi

  if awk "BEGIN {exit !(${MAX_CPU} > 80)}" 2>/dev/null; then
    echo "  判定-峰值: ❌ 不通过 (峰值 ${MAX_CPU}% > 80%)"
    PASS=false
  else
    echo "  判定-峰值: ✅ 通过 (峰值 ${MAX_CPU}% < 80%)"
  fi

  if [ "$PASS" = true ]; then
    echo "  综合判定: ✅ 通过"
  else
    echo "  综合判定: ❌ 不通过"
  fi
else
  echo "  ❌ 采样失败"
fi

echo ""
echo "CPU 日志: ${CPU_LOG}"
SCRIPT

chmod +x /tmp/perf_cpu_load.sh
bash /tmp/perf_cpu_load.sh
```
